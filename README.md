# CodeAlpha Handwritten Digit Recognition

## Project Overview

This project recognizes handwritten digits using a Convolutional Neural Network (CNN) and the MNIST dataset.

## Dataset

The MNIST dataset contains handwritten digit images from 0 to 9.

- Training images: 60,000
- Test images: 10,000
- Image size: 28 × 28 pixels

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- Seaborn
- Google Colab

## Model

A Convolutional Neural Network (CNN) was trained for 5 epochs.

The model achieved a test accuracy of approximately 99.11%.

## Results

The model successfully predicts handwritten digits from the MNIST test dataset.

Example predictions and a confusion matrix are included in the notebook.

## Files

- `handwritten_digit_recognition.ipynb` — Google Colab notebook containing the complete project.

## How to Run

Open the `.ipynb` notebook in Google Colab and run the cells from top to bottom.
